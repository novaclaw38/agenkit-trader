# AgenKit Trader UI Implementation Plan

**Goal:** Build the local read-only web UI described in `docs/superpowers/specs/2026-10-22-ui-design.md`.

**Architecture:** `agenkit_trader/ui/readers.py` (pure functions: files in, JSON-able dicts out, never raising), `ui/page.py` (one static HTML string, vanilla JS), `ui/server.py` (stdlib `ThreadingHTTPServer`-free `HTTPServer`, GET-only whitelist), and an `agenkit ui` subcommand in `cli.py`.

**Tech Stack:** Python 3.12+ stdlib `http.server`, pyyaml, pytest, ruff, mypy strict. No new dependencies.

## Global Constraints

- Read-only, loopback only, GET only, fixed routes, re-read on every request, no threads, no keys.
- No import of execution/exchange/runtime modules (tested).
- Show only numbers present in files; no placeholders; no stack traces or paths in the page.
- Do not touch research outputs, risk/gate or runtime logic.
